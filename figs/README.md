# Figuras

La versión reproducible del notebook genera como salidas canónicas, para cada estación:

- `*_box_N2_dark_nofill_micro_amp1.png`
- `*_theta_profile_dark.png`
- `*_composites_barras_dark.png`

Los archivos con nombres más cortos (`*_box_N2.png`, `*_theta_profile.png`, `*_hist_unificado_N2.png`, etc.) son iteraciones históricas. Se conservaron para no eliminar resultados previos, pero no deben mezclarse con las figuras canónicas porque algunos se calcularon con N² 1000–850 hPa o con una versión anterior de la climatología.
